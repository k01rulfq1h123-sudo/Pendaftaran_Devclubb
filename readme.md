# Documentation: Portal Pendaftaran DevClub SMK Tunas Media

## 1. Deskripsi Proyek

Portal Pendaftaran DevClub SMK Tunas Media merupakan sistem pendaftaran anggota klub coding berbasis web interaktif dengan arsitektur Client-Server.

Sistem ini dibuat menggunakan:

- HTML5 sebagai struktur halaman.
- TailwindCSS sebagai framework untuk tampilan antarmuka.
- JavaScript sebagai Client-Side Logic.
- RegEx untuk validasi format NIS.
- Fetch API untuk pengiriman data secara asynchronous.
- PHP sebagai Backend REST API.
- MySQL sebagai database penyimpanan data pendaftaran.
- Prepared Statement untuk meningkatkan keamanan query database.

Sistem memungkinkan siswa Konsentrasi Keahlian RPL SMK Tunas Media untuk melakukan pendaftaran DevClub melalui formulir online.
